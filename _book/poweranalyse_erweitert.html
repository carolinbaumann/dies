8  Poweranalyse

Eine Poweranalyse hilft dabei, die erforderliche Stichprobengröße für eine Studie zu bestimmen. Ziel ist es, einen tatsächlich vorhandenen Effekt mit ausreichender Wahrscheinlichkeit zu entdecken.

Sie unterstützt damit eine begründete Studienplanung:

  • Zu kleine Stichproben können reale Effekte übersehen.
  • Unnötig große Stichproben verbrauchen zusätzliche Zeit und Ressourcen.
  • Die geplante Stichprobengröße wird transparent und methodisch nachvollziehbar begründet.

8.1 Zentrale Größen

Eine Poweranalyse verbindet vier Größen miteinander:

  1. Effektgröße
    Beschreibt, wie stark ein erwarteter Unterschied oder Zusammenhang ausfällt. Beim Vergleich zweier Gruppen wird häufig Cohen’s (d) verwendet.

  2. Signifikanzniveau (alpha)
    Das Signifikanzniveau α bezeichnet die langfristige Wahrscheinlichkeit, die Nullhypothese abzulehnen, obwohl sie gilt, sofern das Testverfahren und seine Annahmen eingehalten werden.

  3. Power (1-beta)
    Beschreibt die Wahrscheinlichkeit, einen tatsächlich vorhandenen Effekt statistisch zu erkennen.

  4. Stichprobengröße (N)
    Gibt an, wie viele Personen für die Untersuchung benötigt werden.

Sind drei dieser Größen festgelegt, kann die vierte bestimmt werden.

8.2 Was bedeutet statistische Power?

Eine Power von 0,80 bedeutet: Wenn der angenommene Effekt tatsächlich existiert, wird er in 80 % vergleichbarer Studien als statistisch signifikant erkannt.

Die Gegenwahrscheinlichkeit ist der Fehler 2. Art:

[ beta = 1 - Power ]

Bei einer Power von 0,80 beträgt beta = 0,20. In 20 % vergleichbarer Studien würde ein tatsächlich vorhandener Effekt übersehen.

Typische Zielwerte sind:

Power Einordnung
0,80 häufig verwendeter Mindeststandard
0,90 höhere Sicherheit, meist größere Stichprobe
0,95 sehr hohe Sicherheit, deutlich größerer Stichprobenbedarf
Hinweis

Der passende Zielwert hängt vom Forschungsziel, vom Risiko eines übersehenen Effekts und von den verfügbaren Ressourcen ab. Eine Power von 0,80 ist eine häufig verwendete Konvention, aber kein allgemeingültiges Naturgesetz.

8.3 Folgen einer zu geringen Power

Studien mit geringer Power haben mehrere Probleme:

  • Tatsächlich vorhandene Effekte werden häufiger übersehen.
  • Ergebnisse fallen von Studie zu Studie instabiler aus.
  • Statistisch signifikante Effekte werden tendenziell überschätzt (auch “Type M Error genannt) oder ihr Vorzeichen gar falsch wiedergegeben (auch”Type S Error genannt”)
  • Die Reproduzierbarkeit der Befunde sinkt.

Die Poweranalyse sollte deshalb bereits vor der Datenerhebung erfolgen und gemeinsam mit Forschungsfrage, Design und Auswertungsstrategie geplant werden.

8.4 Zusammenhänge verstehen am Beispiel: Vereinfachte Fallzahlplanung t-Test

Dieses Beispiel dient ausschließlich zur Illustration der grundlegenden Zusammenhänge. Für Prä-Post-Designs, mehrere Messzeitpunkte, Cluster-Randomisierung, ungleiche Gruppengrößen oder hierarchische Daten ist eine designspezifische Poweranalyse erforderlich.

jstat = require("jstat@1.9.6")

function calculateSampleSize(d, alpha, targetPower, ratio) {
  // Eingabeprüfung
  if (!Number.isFinite(d) || d <= 0) {
    throw new Error("Die Effektgröße d muss größer als 0 sein.");
  }

  if (!Number.isFinite(alpha) || alpha <= 0 || alpha >= 1) {
    throw new Error("α muss zwischen 0 und 1 liegen.");
  }

  if (!Number.isFinite(targetPower) || targetPower <= 0 || targetPower >= 1) {
    throw new Error("Die Power muss zwischen 0 und 1 liegen.");
  }

  if (!Number.isFinite(ratio) || ratio <= 0) {
    throw new Error("Das Gruppenverhältnis muss größer als 0 sein.");
  }

  // Kritische Z-Werte für einen zweiseitigen Test
  const zAlpha = jstat.normal.inv(1 - alpha / 2, 0, 1);
  const zPower = jstat.normal.inv(targetPower, 0, 1);

  /*
   * Verhältnis:
   * ratio = n2 / n1
   *
   * Normalapproximation für den Vergleich zweier
   * unabhängiger Mittelwerte bei gemeinsamer Standardabweichung.
   */
  const n1Raw =
    Math.pow(zAlpha + zPower, 2) *
    (1 + 1 / ratio) /
    Math.pow(d, 2);

  const n2Raw = ratio * n1Raw;

  // Gruppengrößen jeweils separat aufrunden
  const n1 = Math.ceil(n1Raw);
  const n2 = Math.ceil(n2Raw);

  /*
   * Näherungsweise erreichte Power nach dem Aufrunden.
   *
   * Standardfehler der standardisierten Mittelwertsdifferenz:
   * sqrt(1/n1 + 1/n2)
   */
  const noncentrality =
    d / Math.sqrt(1 / n1 + 1 / n2);

  const achievedPower =
    jstat.normal.cdf(-zAlpha - noncentrality, 0, 1) +
    1 - jstat.normal.cdf(zAlpha - noncentrality, 0, 1);

  return {
    n1,
    n2,
    total: n1 + n2,
    achievedPower
  };
}

sample_sizes = calculateSampleSize(
  effect_size,
  alpha,
  power,
  ratio
)

8.4.1 Interpretation der Effektgröße

  • d = 0.2: Kleiner Effekt
  • d = 0.5: Mittlerer Effekt
  • d = 0.8: Großer Effekt
