6  Randomisierung

6.1 Was ist Randomisierung?

Randomisierung bezeichnet die zufällige Zuweisung von Untersuchungsteilnehmenden zu den verschiedenen Untersuchungsbedingungen einer Studie, beispielsweise einer Experimental- und einer Kontrollgruppe. Sie stellt ein zentrales Merkmal experimenteller Forschungsdesigns dar und dient dazu, systematische Unterschiede zwischen den Gruppen zu minimieren.

Durch die zufällige Gruppenzuweisung werden sowohl bekannte Merkmale (z. B. Vorwissen, Motivation oder Alter) als auch unbekannte Einflussfaktoren im Erwartungswert gleichmäßig auf die Untersuchungsgruppen verteilt. Auf diese Weise erhöht sich die Wahrscheinlichkeit, dass beobachtete Unterschiede in den Ergebnissen tatsächlich auf die untersuchte Intervention zurückzuführen sind.

Randomisierung trägt somit wesentlich zur internen Validität einer Studie bei und bildet eine wichtige Grundlage für die Ableitung kausaler Aussagen.

6.2 Zentrale Funktionen der Randomisierung

Randomisierung soll verhindern, dass die Gruppenzuweisung systematisch von Merkmalen der Teilnehmenden beeinflusst wird. Dadurch werden bekannte und unbekannte Einflussfaktoren im Erwartungswert auf die Gruppen verteilt.

Das stärkt die interne Validität und macht kausale Interpretationen plausibler.

6.3 Beispiel aus der Deutschdidaktik

Eine Studie untersucht ein neues Lesestrategieprogramm. Die Interventionsgruppe arbeitet mit dem Programm, die Kontrollgruppe erhält regulären Unterricht.

Werden die Gruppen gezielt ausgewählt, könnte beispielsweise die leistungsstärkere Klasse das neue Programm erhalten. Unterschiede im Abschlusstest wären dann schwer zu interpretieren.

Durch eine zufällige Zuweisung wird diese systematische Auswahl vermieden.

6.4 Möglichkeiten der zufälligen Zuweisung

6.4.1 Einfache Randomisierung

Bei der einfachen Randomisierung wird jede Person mit gleicher Wahrscheinlichkeit einer Gruppe zugewiesen, zum Beispiel mithilfe eines Zufallszahlengenerators.

Vorteil: Das Verfahren ist leicht verständlich und einfach durchzuführen.

Zu beachten: Bei kleinen Stichproben können unterschiedlich große oder zufällig ungleiche Gruppen entstehen.

6.4.2 Cluster-Randomisierung

In schulischen Studien können häufig nicht einzelne Schüler:innen unabhängig voneinander zugewiesen werden. Stattdessen werden ganze Klassen oder Schulen zufällig einer Bedingung zugeordnet.

Beispiel: Acht Klassen nehmen an einer Studie zur Schreibförderung teil. Vier Klassen werden der neuen Schreibintervention und vier Klassen dem regulären Unterricht zugewiesen.

Zu beachten: Schüler:innen innerhalb einer Klasse ähneln sich häufig. Dies muss bei der Stichprobenplanung und Auswertung berücksichtigt werden.

6.4.3 Stratifizierte Randomisierung

Bei der stratifizierten Randomisierung werden Untersuchungseinheiten zunächst anhand eines wichtigen Merkmals gruppiert und anschließend innerhalb dieser Gruppen randomisiert.

So kann beispielsweise sichergestellt werden, dass Klassen mit hohem und niedrigem Vortestniveau auf beide Bedingungen verteilt werden.

Hinweis

Zu den weiterführenden Verfahren gehört die Blockrandomisierung. Sie wird eingesetzt, um während der Zuweisung ein festgelegtes Verhältnis zwischen den Gruppen zu erhalten.

6.5 Wenn keine Randomisierung möglich ist

In schulischen Studien können organisatorische Vorgaben eine zufällige Zuweisung verhindern. Dann kann Matching helfen, möglichst ähnliche Vergleichsgruppen zu bilden.

Dabei werden Personen, Klassen oder Schulen anhand wichtiger Merkmale einander zugeordnet, zum Beispiel anhand von:

  • Vortestleistung
  • Klassenstufe
  • Schulform
  • Klassengröße

Matching kann die Vergleichbarkeit verbessern. Es ersetzt jedoch keine Randomisierung, weil nur bekannte und gemessene Merkmale berücksichtigt werden können.

Weiterführende Verfahren sind beispielsweise Propensity-Score-Matching und die statistische Kontrolle durch Kovariaten.

6.6 Gruppen nach der Randomisierung beschreiben

Nach der Randomisierung sollten die Ausgangsmerkmale der Gruppen deskriptiv dargestellt werden, beispielsweise:

  • Vortestleistungen
  • Alter oder Klassenstufe
  • weitere für die Forschungsfrage relevante Merkmale

Mittelwerte, Standardabweichungen und Verteilungen zeigen, wie die entstandenen Gruppen zusammengesetzt sind.

Wichtig zu beachten

Unterschiede zwischen den Gruppen bedeuten nicht automatisch, dass die Randomisierung fehlgeschlagen ist. Gerade bei kleinen Stichproben können zufällige Unterschiede auftreten.

Signifikanztests eignen sich daher nicht als Prüfung, ob eine Randomisierung „erfolgreich“ war. Entscheidend ist, dass die Zuweisung korrekt und ohne vorhersehbare Einflussnahme durchgeführt wurde.

6.7 Interaktives Tool: Randomisierung durchführen

Dieses Beispiel dient ausschließlich zur Illustration der grundlegenden Zusammenhänge. Für Prä-Post-Designs, mehrere Messzeitpunkte, Cluster-Randomisierung, ungleiche Gruppengrößen oder hierarchische Daten ist eine designspezifische Poweranalyse erforderlich.

  value: 40,
  step: 1,
  label: "Anzahl Teilnehmende"
})

viewof n_groups = Inputs.range([2, 4], {
  value: 2,
  step: 1,
  label: "Anzahl Gruppen"
})

viewof group_names = Inputs.text({
  label: "Gruppennamen (durch Komma getrennt)",

  placeholder: "Gruppe 1, Gruppe 2, ..."
})

viewof do_randomize = Inputs.button("Randomisierung durchführen")
function randomizeParticipants(n, groups) {
  const groupList = groups.split(',').map(g => g.trim()).slice(0, n_groups);
  
  // Erstelle Array von Teilnehmer-IDs
  const participants = Array.from({length: n}, (_, i) => i + 1);
  
  // Fisher-Yates Shuffle
  for (let i = participants.length - 1; i > 0; i--) {
    const j = Math.floor(Math.random() * (i + 1));
    [participants[i], participants[j]] = [participants[j], participants[i]];
  }
  
  // Weise Gruppen zu
  const assignments = participants.map((id, index) => ({
    id: id,
    group: groupList[index % groupList.length]
  }));
  
  // Zähle Gruppengröße
  const groupCounts = {};
  groupList.forEach(g => groupCounts[g] = 0);
  assignments.forEach(a => groupCounts[a.group]++);
  
  return { assignments, groupCounts, groupList };
}

// Führe Randomisierung durch
randomization = {
  do_randomize; // Abhängigkeit vom Button
  return randomizeParticipants(n_participants, group_names);
}
